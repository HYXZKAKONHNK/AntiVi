# AntiVi
AntiVi – антивирус на Python, созданный на основе встроенных библиотек
# Поддерживает операционные системы:
Windows 11 Home, Pro, Enterprise, Education, loT Enterprise LTSC (26H2, 26H1, 25H2, 24H2, 23H2, 21H2, 22H2 и все остальные версии), Windows 10 Home, Pro, Enterprise, Education, Pro for Workstations, LTSC (1507, 1511, 1607, 1703, 1709, 1803, 1809, 1903, 1909, 2004, 20H2, 21H1, 21H2, 22H2), Windows 8.1 Core, Pro, Enterprise, Pro with media center, RT 8.1, with Bing, SL, N, KN, Blue (с постоянным обновлением ядра, всеми кумулятивными обновлениями и важными оговорками), Windows 7SP1 (KB2533623, KB30638858), Windows 7 RTM (кроме сборки 7600 без SP1)
